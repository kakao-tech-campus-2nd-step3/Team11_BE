채팅, 상담, 서류 등 피해자분들께 실질적인 도움이 되는 기능들을 구현하신 것도 좋았습니다.
사용자의 관점에서 필요한 기능들을 계속 고민하고 발전시키신 부분이 프로젝트 전반에 잘 반영된 것 같습니다



전세 사기 피해자를 돕는 서비스를 만들었습니다.
전세 사기 피해자들이 전세금을 돌려받는 과정 중 가장 큰 어려움은, 부족한 자료와, 커뮤니티 부재, 

   
2. 멤버

   

2. 커뮤니티

   도움이 되는 글에 대해서는 좋아요를 남길수 있습니다~
   사이트 내에 상담기능이 존재해서 커뮤니티 내에서 홍보할수 없도록 전화번호를 남길수 없게 필터링 기능을 뒀습니다~

2. 가이드라인

   피해자의 유형에 따라서 거쳐야하는
   단계에 대한 상세한 안내를 해주고 필요한 경우 관련 사이트 주소를 제공해 이동할수 ㅣㅆ도록 해봤습니답
   
   유저 입장에서 사이트 내에서 유형검사와 해결 방법 서류 작성까지 끝낼수 있어 좋을 것 같습니다~!

3. 서류 완성 기능

   사용자 환경에 따라 파일 편집,작성이 어려울 수 있을텐데 사이트 내에서 입력 다운로드 까지한번에 한게 좋았습니다~

4. 상담

    이거 재빈님이 그 실제 닫히는 시간이랑 상담 종료 시간 다르게 해서 멘토가 좀 유동적으로 종료할수 있게 한다고 했었는데 저는 그거 되게 좋은 것 같습니다 ~!
